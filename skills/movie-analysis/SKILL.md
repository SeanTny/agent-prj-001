# 电影分析

当任务要求根据用户偏好分析电影时：

1. 阅读项目中的 `knowledge.md`。
2. 获取用户喜欢和不喜欢的电影类型。
3. 分析目标电影的类型、剧情特点和主题。
4. 说明符合偏好的地方。
5. 说明可能不符合的地方。
6. 不要仅根据评分判断。
7. 如果信息不足，要明确说明。

## 数据统计工具

如果任务需要统计 movies.csv 中的电影数量或平均评分：

1. 运行 `tools/movie-stats.ps1`。
2. 使用脚本输出的统计结果。
3. 不要自己猜测或手工计算统计结果。
